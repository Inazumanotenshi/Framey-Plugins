# Framey Plugins

A collection of community plugins for **Framey**, the lightweight plugin loader for Steam Frame.

This repository contains plugins developed to extend Steam Frame with additional features, quality-of-life improvements, and experimental ideas inspired by the Steam Deck ecosystem.

---

## About

Most plugins in this repository were created because I personally missed certain functionality in Steam Frame or wanted to experiment with features that are common in projects like Decky Loader.

All plugins are designed for use with Framey and can be installed independently.

Some Plugin Code might be AI generated. If you dont like it dont use it!

---

## Available Plugins

| Plugin | Description |
|----------|----------|
| Battery Detective | Tracks battery usage per game, estimates remaining playtime, and records battery statistics |
| SteamGridDB Framey | Allows to change the artworks of your installed Steam Frame apps with artworks of SteamGridDB |
| More coming soon... | 🚧 |

## Installation

### Via Framey App

1. Download the desired plugin release
2. Open the Framey App
3. Select the ZIP file via Browse
4. Install the ZIP package
5. Reload Framey

### Manual Installation

1. Copy the plugin folder into:

```text
plugins/
```

2. Open Framey Settings.
3. Select **Reload**.

---

Each plugin contains its own documentation, installation instructions, and configuration options.
